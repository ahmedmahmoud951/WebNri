# nri-mobile

تطبيق الجوال لحي **NRI District II**: ساكن، زائر، وموظف تشغيل.  
Android + iOS من كود Flutter واحد. يتكلم مع المنصة فقط: **REST + SignalR + FCM**.

|---|---|
| Package | `sa.nri.nri_mobile` |
| السيرفر الحي | `http://nri.runasp.net` (HTTP) |
| Hub | `/hubs/parking` |
| عقد الـ API | `FINAL-END-POINT.md` + `Finall PFlutter.md` |
| قرارات المنتج | `SA-REPLY-TO-FLUTTER.md` |
| من الـ RFI/العرض | `MOBILE-FROM-RFI.md` |
| مقارنة الويب | [`README-FOR-WEB.md`](README-FOR-WEB.md) |

## تشغيل

```bash
flutter pub get
flutter run
```

حسابات التجريب (الباسورد كلها `admin`):

| username | الدور | ماذا تجرب |
|---|---|---|
| `visitor1` | زائر | جلسة مفتوحة → دفع → إيصال → عدّاد سماح |
| `citizen1` | ساكن | بطاقة QR · اشتراك · حجز · فواتير |
| `employee1` | موظف | إشغال لايف · وارد البلاغات · EV |

للـ Mock من غير سيرفر:

```bash
flutter run --dart-define=USE_MOCK=true
```

أول تشغيل: عربي RTL. من الملف يمكن التبديل لإنجليزي.

## الشكل

خلفية رملية فاتحة، بطاقات بيضاء، لون إجراء تيل (`#0F766E`)، أرقام LTR داخل الصف العربي.  
شارة الدور: زائر برتقالي، ساكن أخضر، موظف تيل.

شريط أسفل ثابت لأربعة أبواب: الرئيسية · الموقف/الجلسة · البلاغات · الحساب.

## الأدوار والشاشات والخواص

تطبيق **واحد**. الصلاحيات من الباك اند. الأدمن على الموبايل يُعرض كموظف.

### شريط التنقل (الكل)

| تبويب | زائر | ساكن | موظف |
|---|---|---|---|
| الرئيسية | مهمة الدفع | الوحدة + QR | رادار الإشغال |
| الثاني | جلستي | الإشغال | الإشغال |
| الثالث | بلاغ جديد | بلاغ جديد | وارد البلاغات |
| الحساب | لغة + لوحة | لغة + لوحة | لغة + لوحة |

### زائر `visitor`

المسار: دخول الحاجز في الواقع → التطبيق يعرض الجلسة → يدفع → 20 دقيقة سماح → يخرج.

| شاشة | خواص |
|---|---|
| الرئيسية | ادفع الآن / إيصال بعد الدفع / عدّاد السماح / أماكن شاغرة |
| جلستي | حالة، لوحة، بوابة، وقت الدخول، السماح |
| الدفع | intent + capture تجريبي (EGP) |
| الإيصال | مبلغ، لوحة، وقت، `graceUntil` |
| التاريخ | جلسات سابقة |
| الإشغال | `zones[]` لايف عبر SignalR |
| بلاغ | تذكرة ضائعة / حاجز / نفايات / صيانة / أخرى |
| خدمات الحي | EV · فواتير (غالباً فاضية) · بلاغ |
| الحساب | مركبة، لغة، خروج |
| بطاقة QR | تظهر بعد الدفع (`kind=session`) وإلا شاشة فاضية 404 |

**ممنوع للزائر:** حجز سلوت (403)، فتح حاجز.

### ساكن `citizen`

| شاشة | خواص |
|---|---|
| الرئيسية | المبنى/الوحدة/اللوحة + بطاقة QR + حجز |
| الإشغال | إشغال مبناه لايف |
| بطاقة QR | `GET /me/pass` — `payload` في الرمز، النوع اشتراك |
| الاشتراك | منطقة رئيسية مضمونة + مناطق اختيارية من غير ضمان |
| الحجز | 1 / 2 / 4 ساعات — المنصة تختار السلوت — QR التأكيد |
| الفواتير | قائمة مستحقة (من غير دفع فاتورة من التطبيق) |
| EV | عدد الشواحن الشاغرة للمبنى |
| بلاغ | نفس الأنواع بما فيها نفايات/صيانة |
| الحساب | حفظ مركبة |

### موظف `employee` (و`admin` على الموبايل)

| شاشة | خواص |
|---|---|
| الرئيسية | عدّاد إشغال + عدد البلاغات |
| الإشغال | كل المناطق، تحديث SignalR من غير زر تحديث |
| وارد البلاغات | قائمة + إنشاء |
| خدمات الحي | EV + فواتير |
| الحساب | ملف |

**مش على الموبايل:** لوحة أدمن، بحث لوحة عبر 31 مبنى، تقارير مالية، ضبط السماح، دعوة زائر، شراء باقة، كاشير، كيوسك.

## الربط

```
Flutter
  REST      لوجين، /me، إشغال، جلسة، دفع، تذاكر، تاريخ، إيصال، QR، اشتراك، حجز، EV، فواتير

```

Base URL: `--dart-define=API_BASE=...`
